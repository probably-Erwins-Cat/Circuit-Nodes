# Contributing to Circuit Nodes

Ideas, issue reports, and new module designs are welcome. A contributed part
should remain usable as the project develops. For example, if someone adds a
needed power-source module, the project must still be able to include it in
complete kits without asking the contributor for permission each time.

Before submitting design files, CAD models, images, documentation, code, or
other original material, please make sure you can grant the permissions below.
If you are unsure about a third-party component or model, discuss it in an
issue before submitting the files.

project documentation and marketing. The project may authorize contractors
and suppliers to carry out those activities on its behalf. This additional
permission is limited to the Circuit Nodes project; it is not a license to use
your contribution in unrelated products. It covers only copyright, design, and

You keep ownership of your contribution and may use or license it elsewhere.
Your contribution remains credited in the project history, along with any
attribution required by the public license.
Please identify any third-party material, its source, and its license in your
pull request. If you cannot grant the permissions above, discuss different
terms with the maintainer before submitting the files. Contributions submitted
before these terms were added are not covered retroactively.
